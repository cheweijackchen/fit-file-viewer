# TrailKit

Hiking tools for analyzing activities and exploring trails.

[trailkit.app](https://fit-file-viewer.vercel.app/)


## Features

### [FIT File Viewer](https://fit-file-viewer.vercel.app/fit-file-viewer)

Drag and drop a `.fit` file from your Garmin, Suunto, or Coros device to analyze your activity.

- Heart rate zone breakdown
- Elevation profile
- GPS route on an interactive map
- Full data records table (timestamp, speed, cadence, and more)

### [Peaks Tracker](https://fit-file-viewer.vercel.app/peaks)

Track your progress on Taiwan's 100 peaks (百岳).

- Interactive map showing all peak locations
- Checklist organized by mountain group
- Progress statistics and shareable summary

### Trail Map *(coming soon)*

A vector map built on MapLibre GL for exploring terrain before you head out.

- 3D terrain and satellite imagery
- Contour lines
- GPX/FIT track playback

## Tech Stack

Next.js · Mantine · Leaflet · MapLibre GL
